Como funcionaHow it works

A página registra uma ferramentaThe page registers a tool

await document.modelContext.registerTool({
  name: "favorite_event",
  title: "Favorite event",
  description: "Add a tech event to the user's favorites.",
  inputSchema: {
    type: "object",
    properties: { eventId: { type: "string" } },
    required: ["eventId"]
  },
  execute: async ({ eventId }) => {
    favorite(eventId);
    return `Favorited ${eventId}`;
  }
});

Fica em document.modelContext, só em contextos seguros. A promise é rejeitada se o nome já estiver em uso. O retorno pode ser qualquer valor serializável em JSON — uma string simples serve.

Lives on document.modelContext, secure contexts only. The promise rejects if the name is already taken. The return value can be any JSON-serializable value — a plain string is fine.

Duas formas de registrarTwo ways to register

Imperativa primeiro, declarativa em esperaImperative first, declarative on hold

await document.modelContext.registerTool({
  name: "favorite_event",
  execute: async ({ eventId }) => { ... }
});

Controle total sobre schema, execução e efeitos colaterais. O Chrome relata que ela é "muito mais popular que a declarativa" e planeja lançá-la primeiro.

Full control over schema, execution and side effects. Chrome reports it is "a lot more popular than the declarative one" and plans to ship it first.

Agente do navegadorBrowser agent

Agentes embutidos (ChatGPT desktop, Brave Leo...) recebem as ferramentas da página por um mecanismo interno e separado do navegador — não pelo getTools().

Built-in agents (ChatGPT desktop, Brave Leo...) get the page's tools through a separate, internal browser mechanism — not through getTools().

Agente in-pageIn-page agent

getTools() e depois executeTool(tool, input, { signal }), que resolve com o resultado serializado como string JSON — ou null se a ferramenta navegou.

getTools() then executeTool(tool, input, { signal }), which resolves with the result serialized as a JSON string — or null if the tool navigated.

Nos dois casos o seu execute() roda, e a página recebe os eventos toolactivated / toolcancel em document.modelContext.

Either way your execute() runs, and the page sees toolactivated / toolcancel events on document.modelContext.

CancelávelCancellable

SegurançaSecurity

Agentes rodam dentro da sua sessãoAgents run inside your session

Modelos leem instruções e dados como um único fluxo de tokens, então texto injetado consegue guiá-los.

Models read instructions and data as one stream of tokens, so injected text can steer them.

🎭
Manifestos maliciososMalicious manifests

O nome, a descrição ou os parâmetros de uma ferramenta podem esconder instruções feitas para sequestrar o agente — prompt injection "invisível para usuários comuns".

A tool's name, description or parameters can hide instructions designed to hijack the agent — prompt injection "invisible to typical users".

☣️
Saída contaminadaContaminated output

Uma ferramenta de um site confiável ainda pode devolver dados de terceiros — comentários, reviews — carregando instruções.

A tool from an otherwise trustworthy site can still return third-party data — user comments, reviews — carrying instructions.

Dados privados + conteúdo não confiável + um jeito de enviar dados para fora = a "tríade letal", suficiente para roubar os dados de um usuário.

Private data + untrusted content + a way to send data out = the "lethal trifecta", enough to steal a user's data.

SegurançaSecurity

Defesa em camadasDefense in depth

O Chrome recomenda as três. O MCP usa a mesma ideia, e diz que clientes devem tratar hints de servidores não confiáveis como não confiáveis.

Chrome recommends all three. MCP uses the same idea, and says clients must treat hints from untrusted servers as untrusted.

Atenção: um site malicioso pode omitir ou falsear os hints. Nas palavras da OpenAI, "o nome de uma ferramenta, ou a alegação de que ela só lê dados, não é prova do que ela faz" (tradução livre) — combine hints com controles reais. Agentes devem assumir que ferramentas alteram estado, confirmar com o usuário e destacar (spotlighting) saídas não confiáveis.

Caveat: a malicious site can omit or misrepresent hints. As OpenAI puts it, "a tool's name or claim that it only reads data isn't proof of what it does" — pair hints with real controls. Agents should assume tools mutate state, confirm with the user, and spotlight untrusted output.

O debateThe debate

"Um agente agindo em nome de um usuário é, na prática, tecnologia assistiva: ele deveria operar o site como o usuário operaria, e o site não deveria tratá-lo de forma diferente."

WebKit — posição: contra (tradução livre)

"An agent acting on a user's behalf is, in effect, assistive technology: it should operate a site as the user would, and the site should not single it out for different treatment."

WebKit — position: oppose

"Num cenário adversarial, há o risco de sites oferecerem ferramentas que não correspondem à experiência de um usuário na página […] fornecerem prompt injection invisível para usuários comuns, coletarem dados do usuário a partir das entradas das ferramentas."

Mozilla — posição: neutra (tradução livre)

"In an adversarial setting there is a risk that sites will provide tools that do not match the experience of a user on the page […] provide prompt injection that is invisible to typical users, collect user data from the inputs of the tools."

Mozilla — position: neutral

Até o fórum é disputado: a Apple avisa que fará uma objeção formal se o WebMCP for para o Web Machine Learning Working Group do W3C, e sugere um novo grupo sobre a web agêntica.

Even the venue is contested: Apple says to expect a formal objection if WebMCP moves into the W3C Web Machine Learning Working Group, and suggests a new agentic-web group instead.
